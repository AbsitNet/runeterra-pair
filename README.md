# Пара из Рунтерры

[English version](README.en.md)

Тест для тех, кто хоть раз задумывался, с кем из чемпионов League of Legends у него могло бы что-то сложиться. Сделал по просьбе жены.

Играть: **https://absitnet.github.io/runeterra-pair/**

## Как это устроено

На экране два чемпиона, выбираешь того, с кем отношения сложились бы лучше. Потом следующая пара, потом ещё одна. Кнопки «не могу выбрать» нет специально: каждый выбор что-то значит, поэтому и результат получается честный.

Одно поражение никого не выбивает. Сначала все играют несколько кругов по швейцарской системе против соперников с похожим счётом. Потом те, чьё место ещё под вопросом, продолжают драться, пока всё не станет ясно. Лучшие выходят в плей-офф с сеткой второго шанса, а финал решается один на один.

В конце будет полный тир-лист, твой «типаж», пара шуточных ачивок, три чемпиона, с которыми точно ничего бы не вышло (и почему), и сертификат о совместимости. Его можно сохранить картинкой и отправить куда угодно. У каждого победителя есть своя фраза из официальной биографии, она будет и на экране итогов, и в сертификате.

Результатом можно поделиться ссылкой. По ней тир-лист откроется у кого угодно, никакая комната для этого не нужна.

Участников 138, только взрослые: без детей и йордлов. Рааст и Каин считаются разными людьми, Волк и Овечка тоже. Чудищ вроде Ка'Зикса и Варвика можно убрать одним переключателем.

Полный турнир занимает от 20 до 40 минут, смотря какой режим выбрать. Если столько времени нет, есть мини-турниры на 16 участников, минуты на три: Иония, Ноксус, Демасия, Пилтовер и Заун, злодеи, маги, убийцы или только новые чемпионы. С телефона можно не нажимать, а свайпать.

Тест можно поставить на телефон как приложение: в Chrome через «Установить», на iPhone через «Поделиться» → «На экран „Домой“». После первого запуска соло-режим работает и без интернета.

## Вдвоём

Создаёшь комнату, кидаешь ссылку, и каждый проходит свой турнир на своём устройстве. Перед стартом можно поставить на то, кто станет парой другого. Видно, кто сколько уже прошёл, а когда оба закончат, открывается сравнение: насколько совпали вкусы и чья ставка сыграла.

Дальше ваши победители встречаются в последней дуэли, «битве вкусов», и голосуете вы оба. Есть общий сертификат на двоих, где ваши общие любимцы расписываются как свидетели, и мини-игра, в которой надо угадать, кого выбирал другой.

## Как запустить у себя

Сборки нет, это обычный статический сайт. Подойдёт любой локальный сервер:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.

Комната на двоих работает через Supabase. Нужно применить миграцию из `supabase/migrations/` и вписать адрес проекта и публичный ключ в `js/config.js`. Публичный ключ в репозитории — это нормально: таблицы закрыты RLS, и браузер ходит в базу только через несколько функций `pair_*`. Комнаты, в которые 90 дней никто не заходил, удаляются сами.

Если Supabase под рукой нет, комнату можно погонять локально: открой две вкладки с `?room-backend=local`.

Для GitHub Pages: Settings → Pages → Deploy from a branch → `main`, `/ (root)`.

Логика турнира лежит в `js/engine.js`, описания чемпионов в `js/profiles.js`, интерфейс в `js/app.js`.

### В планах

| Фича | Что это | Сложность |
|---|---|---|
| Реакции в реальном времени | Когда партнёр доходит до плей-офф, тебе приходит, между кем он выбирает, и можно ответить реакцией. Для тех, кто не любит спойлеры, отключается | средне |
| Синхронные дуэли | Одна и та же пара у обоих одновременно, выбор втайне, ответы открываются разом. В конце общий тир-лист пары | средне |
| Статистика всех игроков | Анонимно: кого чаще всего выбирают и насколько редкий твой выбор | средне |
| Карта сердца | Карта Рунтерры с отметками, откуда родом твой топ-20, сохраняется картинкой | средне |
| Взаимность | Обратный тест «а ты бы понравилась своей паре?»: несколько вопросов с точки зрения победителя и процент взаимности в конце | средне |
| Английский, немецкий и французский | Перевод интерфейса, описаний чемпионов и цитат | долго |
| Комната для компании | Больше двух человек: кто с кем совпадает по вкусам и общий антитоп | долго |
| «Звёздная сваха» | Отдельный режим без дуэлей: примерно 30 вопросов о себе (характер, что ценишь, каким видишь идеальный вечер, как ведёшь себя в ссоре), а сваха подбирает идеального партнёра и объясняет, почему именно его | долго |
