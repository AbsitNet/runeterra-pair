# Пара из Рунтерры

[English version](README.en.md)

Тест для тех, кто хоть раз задумывался, с кем из чемпионов League of Legends у него могло бы что-то сложиться. Сделал по просьбе жены.

Играть: **https://absitnet.github.io/runeterra-pair/**

## Как это устроено

На экране два чемпиона, выбираешь того, с кем отношения сложились бы лучше. Потом следующая пара, потом ещё одна. Кнопки «не могу выбрать» нет специально: каждый выбор что-то значит, поэтому и результат получается честный.

Одно поражение никого не выбивает. Сначала все играют несколько кругов по швейцарской системе против соперников с похожим счётом. Потом те, чьё место ещё под вопросом, продолжают драться, пока всё не станет ясно. Лучшие выходят в плей-офф с сеткой второго шанса, а финал решается один на один.

В конце будет полный тир-лист, твой «типаж», пара шуточных ачивок, три чемпиона, с которыми точно ничего бы не вышло (и почему), и сертификат о совместимости. Его можно сохранить картинкой и отправить куда угодно.

Участников 138, только взрослые: без детей и йордлов. Рааст и Каин считаются разными людьми, Волк и Овечка тоже. Чудищ вроде Ка'Зикса и Варвика можно убрать одним переключателем.

Полный турнир занимает от 20 до 40 минут, смотря какой режим выбрать. С телефона можно не нажимать, а свайпать.

## Вдвоём

Создаёшь комнату, кидаешь ссылку, и каждый проходит свой турнир на своём устройстве. Видно, кто сколько уже прошёл, а когда оба закончат, можно посмотреть, насколько совпали вкусы. Ещё есть мини-игра: попробовать угадать, кого выбирал другой.

## Как запустить у себя

Сборки нет, это обычный статический сайт. Подойдёт любой локальный сервер:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.

Комната на двоих работает через Supabase. Нужно применить миграцию из `supabase/migrations/` и вписать адрес проекта и публичный ключ в `js/config.js`. Публичный ключ в репозитории — это нормально: таблицы закрыты RLS, и браузер ходит в базу только через несколько функций `pair_*`. Комнаты, в которые 90 дней никто не заходил, удаляются сами.

Если Supabase под рукой нет, комнату можно погонять локально: открой две вкладки с `?room-backend=local`.

Для GitHub Pages: Settings → Pages → Deploy from a branch → `main`, `/ (root)`.

Логика турнира лежит в `js/engine.js`, описания чемпионов в `js/profiles.js`, интерфейс в `js/app.js`.

## Что дальше

Идеи на будущие обновления:

- английская, немецкая и французская версии интерфейса;
- общий сертификат пары: одна картинка на двоих с вашими победителями, процентом совпадения вкусов и общими любимцами в роли свидетелей;
- ставка на партнёра: перед стартом каждый угадывает, кто станет парой другого, а в конце видно, кто кого лучше знает;
- битва вкусов: когда оба закончили, ваши победители встречаются в одной дуэли, и голосуете вы оба;
- реакции в реальном времени: когда партнёр доходит до плей-офф, тебе приходит, между кем он выбирает, и можно ответить реакцией (для тех, кто не любит спойлеры, это отключается);
- синхронные дуэли: одна и та же пара у обоих одновременно, выбор втайне, ответы открываются разом, а в конце получается общий тир-лист пары;
- комната для компании, где больше двух человек: кто с кем совпадает по вкусам и общий антитоп;
- тематические мини-турниры на 16 участников минут на десять: только Иония, только злодеи, только маги, только новые чемпионы;
- ссылка на результат: тир-лист открывается по ссылке без всякой комнаты, его можно просто переслать друзьям;
- запуск как приложение: иконка на главном экране телефона, тест открывается на весь экран, а соло-режим работает без интернета.
