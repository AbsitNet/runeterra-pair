# Портреты в двойном разрешении — незаконченная работа

Готовые портреты уже лежат в `img/hd/` (616×1120) и `img/` (308×560, пережаты из увеличенных). Остальные ещё нужно досчитать.

1. `prep.py` собирает исходники в родном разрешении: арты загрузки Data Dragon (зеркало InFinity54/LoL_DDragon на GitHub) и вырезки из сплэшей для Рааста, Волка, Овечки и Омики (Омика — по центру сплэша `Sett_66`).
2. `edsr.py` увеличивает их в 2 раза моделью EDSR_x2.pb (OpenCV dnn_superres, opencv-contrib-python-headless 4.10) по плиткам 112 px — около минуты на портрет на двух ядрах. Уже готовые пропускает.
3. `final.py` пишет `img/hd/{id}.webp` (качество 86) и `img/{id}.webp` (качество 88).
4. `hd_plumbing.patch` — код, который грузит крупные портреты (дуэль, итоги, профиль, сертификаты) с запасным вариантом и обновляет кэш сервис-воркера до `rp-app-v2`. Накладывать, когда готовы все 145.
